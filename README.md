# Hospital Management System

A hospital appointment management platform built with React,
TypeScript, Java Spring Boot microservices, and MySQL.

## Applications

- Frontend: React + TypeScript + Vite
- Auth Service: Spring Boot
- Doctor Service: Spring Boot
- Appointment Service: Spring Boot
- Consultation Service: Spring Boot
- API Gateway: Spring Cloud Gateway
- Database: MySQL

## Frontend Setup

cd frontend
npm install
npm run dev

## Backend Setup

Configure the required environment variables first.
Then run the desired Spring Boot service using its Maven Wrapper.
